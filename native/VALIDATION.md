## 0.4 双向与粘贴实测

- Mac 真 TLS 集成测试新增：手机文字接收且不自动回传，超过 32 MiB 文件上传后回读校验一致，文件名路径隔离，错误 SHA-256 拒绝且清理临时文件。
- vivo 独立测试 APK（与 CopyMore 不同 UID、无读取私有应用数据权限）获取系统剪贴板：Mac 测试 PNG 自动下载后，得到 image/png URI，可读取且 SHA-256 与原图一致；PDF 小文件同样通过 application/pdf URI 跨应用读取与哈希验证。未点击 CopyMore 的复制按钮。
- 手机独立测试应用复制文字、复制 PNG URI，回到 CopyMore 自动发送；Mac 系统剪贴板文字一致，图片文件 URL 对应文件的 SHA-256 一致。测试只使用合成样本，不打印原剪贴板内容。
- 手机独立测试应用通过系统 ACTION_SEND 分享 PDF 到 CopyMore，Mac 系统剪贴板文件 URL 与原文件 SHA-256 一致。
- vivo 实际屏幕检查通过：显示测试图片预览、系统 MIME 类型图标及“已写入剪贴板”状态。文件粘贴取决于目标应用是否处理 content URI；这不代表所有聊天应用的文件粘贴均兼容。
- 测试后恢复 Mac 原剪贴板，移除独立测试 APK；两端应用更新到 0.4.0，保留配对。

## 后台实机复测（2026-10-19）

在 vivo 用户确认「允许后台耗电」后，0.3.2 保留原配对覆盖安装。普通应用进程下测试（未使用会改变进程优先级的 instrumentation）：退到桌面 120 秒无冻结；只移除 CopyMore 自己的任务栈，确认 onTaskRemoved 回调，持续 60 秒 TCP 与心跳正常；随后锁屏 60 秒，确认锁屏期间收到新心跳。测试后唤醒屏幕，未修改锁屏凭据。以上为短时、USB 连接条件下的验证，不代表整夜待机或所有厂商机型。

## 已审阅的 Lint 提示

- BatteryLife：本地局域网持续接收是核心功能，后台授权由用户主动触发；不依赖云推送。当前为开发安装包，正式商店发布前仍需核对权限使用资格。

- 3 条依赖版本提示：本版固定在已能完成构建的 AndroidX / Compose 版本，后续统一升级与兼容性验证。
- 自定义 X509TrustManager：局域网使用扫码获得的证书指纹作为信任锚点；代码校验证书有效期及完整 SHA-256，测试确认错误证书被拒绝。没有无条件信任任意证书。
- 静态 Context：Repository 构造入口只传递 `applicationContext`，不持有 Activity 或 View。
- 2 条可用空间检查提示：当前按文件系统实际剩余空间保守判断，未把系统可清理的其他缓存计入可用容量，也不自动清理其他应用缓存。空间不足时提示用户清理后重试。

## 待真机验收 / 未验证

- vivo V2217A（Android 16 / API 36）：复现退到桌面后约 20 秒 TCP 连接消失。前台服务和进程均存在，Android 标准网络策略 effective=NONE，但 vivo 自有进程标记 isFrozen=true。仅允许 Android 电池优化豁免后仍复现；用户在 vivo 后台耗电管理选择“允许后台耗电”后，前台恢复连接、退到桌面每 20 秒采样，连续 120 秒连接保持且无 vivo 冻结。未修改全局电池策略或其他应用权限。通知权限仍是用户拒绝状态，未代为修改。
- 相机扫码、具体聊天应用的粘贴兼容性、下载进度交互、图片分享/另存、长期后台接收尚待完整真机验收；系统剪贴板的跨应用图片/文件读取已通过上述测试。
- macOS 原生窗口尚未进行视觉与交互自动验收；局域网授权及登录时启动需在应用包内继续验证；实际应用已使用本地文件启动成功。
- 局域网 DNS-SD 发现、路由器隔离条件、Wi-Fi 切换、电脑睡眠唤醒和手机后台限制需两台实机联测。测试覆盖了底层认证重连，未覆盖真实路由器上的发现过程。
- Android 后台与锁屏短时连接测试已通过；长时间持续接收、手机重启及其他厂商省电策略仍需要单独验证。不能保证系统强制停止后继续工作。
- 图片与文件 URI 在目标 App 中的粘贴兼容性需逐一验证；原生分享和保存作为入口已实现。
- 本机只有 Apple Command Line Tools，缺少 XCTest 模块，`swift test` 无法运行。XCTest 源码保留，实际验证由 TLS 集成测试及 Android/JVM 测试承担。
- Apple Silicon、其他 macOS 版本、多个 Android 系统版本尚未运行验证。
- 发布签名、Apple 公证、商店发布、多文件、断点续传、多个手机上传冲突处理尚未实现。

## 推荐实机顺序

1. 两端安装，允许需要的权限，同一 Wi-Fi 扫码配对。
2. 从 Mac 复制中文/表情文字，在手机输入框粘贴；截图、Finder 中的单个图片/PDF 分别测试点击下载、复制、分享和另存；大文件复测取消、失败重试及剩余空间不足。
3. 关闭并重开两端，确认不重新扫码即可连接；切换网络、Mac 休眠唤醒后复测。
4. 手机退到后台和锁屏，观察通知、接收和系统剪贴板行为；复测暂停与恢复。
5. 在 Mac 撤销手机，确认连接断开、旧令牌无法重新连接，再扫码恢复。
